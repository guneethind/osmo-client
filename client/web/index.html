Technical details

Status push 02/80

Status topics (00/99)

Experimental. Up to four cameras at once: the active one and three more. The computer can't join several cameras' own Wi-Fi at once, so each extra camera joins a shared network: set one for it in Cameras → Wi-Fi → Change (the active camera can keep its own Wi-Fi if the computer reaches the shared network over Ethernet). Recording starts and stops on all of them together, but not frame-accurately; check each camera's tile. Removing a camera puts it back on its own Wi-Fi.
